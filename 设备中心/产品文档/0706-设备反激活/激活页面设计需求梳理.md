# 经销商测试免激活页面设计需求梳理

## 三、关键设计结论

| 点 | 结论 |
|---|---|
| 模块名称 | 后台模块可叫“经销商管理”，菜单入口用“经销商列表” |
| 日志名称 | 统一叫“App测试操作日志”，不叫“免激活日志” |
| 新增App测试账号 | 需要发起钉钉审批 |
| 延期 | 不需要钉钉审批，平台运营人员直接修改有效期并记录App测试操作日志 |
| 停用 / 撤销 | 不需要钉钉审批，直接生效并级联测试绑定 |
| 组织状态 | 只读展示，来自组织中心，不在设备中心操作 |
| APP端原型 | 本期不做独立APP原型，只在后台表达测试链路与结果 |

## 四、原型边界

### 本期做

- 经销商列表
- 经销商详情
- App测试账号列表、详情、新增、延期、启用/停用、撤销
- 测试设备列表与状态
- 经销商维度App测试操作日志
- 全局App测试操作日志
- 钉钉审批状态表达
- 激活、云存、流量抑制结果表达

### 本期不做

- 独立APP测试账号体验原型
- 真实钉钉审批接口
- 真实用户中心接口
- 真实设备绑定接口
- 抽检任务中心
- 复杂风控策略
- 独立数据看板

│   └── 决策
