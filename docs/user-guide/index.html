01

APP 测试账号是做什么的

APP 测试账号是提供给经销商测试人员使用的专用账号，主要用于设备抽检、样机交付前验证和设备异常复测。测试人员可在 APP 中完成扫码添加、配网、上线检查、音视频、基础控制和 4G 通信测试。

它解决了什么问题

普通账号添加设备可能被系统当成真实用户首次激活，导致激活时间被提前写入、正式权益被提前消耗，并影响真实激活统计。使用 APP 测试账号后，系统只建立临时测试关系，不把抽检行为当成正式销售和正式激活。

经销商测试行为系统处理结果
扫码添加设备建立测试关系，可完成约定的基础测试
设备正式激活不触发
首次激活时间不写入
正式云存权益不生效、不提前消耗
正式流量套餐不生效、不提前消耗
真实激活统计不计入
测试结束经销商测试人员在 APP 端解绑设备
“设备反激活”的准确含义不是先激活再回退，而是在正式激活发生前识别测试账号并阻止正式激活。
02

跟单人员与测试人员的分工

角色主要工作
跟单管理人员查找经销商、创建账号、安全交付临时密码、重置密码、查询设备测试记录和操作日志
经销商测试人员使用测试账号登录 APP、扫码添加设备、完成设备测试、测试结束后在 APP 端解绑设备
记住这条分工跟单人员负责“账号和记录”，经销商测试人员负责“实际测试和解绑”。
03

完整使用流程

  1. 确认信息经销商、所属大区、APP 客户端
  2. 选择经销商在左侧查询并核对经销商 ID
  3. 检查现有账号避免同一用途重复创建
  4. 创建并交付创建账号，安全交付临时密码
  5. 设备测试测试人员登录 APP 并扫码测试
  6. 查询记录跟单人员核对设备添加情况
  7. APP 端解绑测试结束后解除临时测试关系
  8. 日志追溯按日期查询后台操作记录
04

进入页面并认识页面布局

进入路径：设备中心 > 经销商列表。左侧用于查询和选择经销商，右侧用于查看设备测试记录、APP 测试账号和操作日志。

先检查大区中国、亚洲、北美、欧洲四个大区会同时影响设备测试记录、APP 测试账号和操作日志。查询不到数据时，先检查大区是否正确。
05

操作一：查询并选择经销商

  1. 在左侧“经销商名称 / ID”输入框中输入经销商名称或经销商 ID。
  2. 点击“查询”。
  3. 在查询结果中点击目标经销商。
  4. 核对右侧经销商名称、经销商 ID、简称、创建时间和设备总数。

经销商名称支持模糊查询；经销商 ID 可直接查询，例如 DL-1001。点击“重置”可清空条件并恢复全部经销商。

06

操作二：查看和查询 APP 测试账号

  1. 在右上方选择正确的大区。
  2. 点击“APP 测试账号”标签。
  3. 在“账号名称 / 用户 ID”中输入关键词筛选账号。
  4. 核对账号名称、用户 ID、所属大区、客户端和创建时间。
操作用途
查看打开用户中心详情，进一步核对账号信息
重置密码密码遗失或需要重新交付时生成新密码
当前页面功能边界暂不提供账号有效期、权限状态、启用、停用、延期和审批操作。
07

操作三：创建 APP 测试账号

创建前先确认

  • 经销商和所属大区正确。
  • 经销商当前允许创建账号；停用经销商只能查看。
  • 已确认需要使用“小鹰看看”还是“小鹰视界”。
  • 现有账号中没有合适账号，避免重复创建。

创建步骤

  1. 在“APP 测试账号”标签中点击“创建账号”。
  2. 核对系统自动带入的经销商组织。
  3. 填写账号名称并选择账号所属大区。
  4. 选择客户端名称，客户端 ID 会自动带出。
  5. 填写创建原因，例如“用于到货设备抽检和异常复测”。
  6. 点击“创建账号”。
字段必填填写要求
经销商组织是自动带入当前经销商，只读
账号名称是建议包含经销商或场景；同一经销商下不能重名
账号所属大区是中国、亚洲、北美、欧洲
客户端名称是选择“小鹰看看”或“小鹰视界”
客户端 ID是系统自动带出，不可编辑
创建原因是说明抽检、样机验证或异常复测用途，最多 200 字

创建成功后如何处理临时密码

  • 临时密码共 10 位，只包含大写字母、小写字母和数字，三类字符至少各有 1 位。
  • 密码只在成功弹窗中展示一次，关闭后不能再次查看。
  • 点击“复制密码”，将账号名称、客户端和密码通过一对一安全方式交付指定人员。
  • 建议留存用户 ID，便于后台查询；不要在公开群聊、工单备注或共享表格中记录真实密码。
关闭前必须确认临时密码已经正确、安全地交付。密码遗失后只能重置，不能找回。
08

操作四：重置 APP 测试账号密码

适用于临时密码遗失、测试人员无法登录，或需要重新交付账号的情况。

  1. 进入目标经销商的“APP 测试账号”标签并选择正确大区。
  2. 找到目标账号，点击“重置密码”。
  3. 核对经销商、账号名称和用户 ID。
  4. 填写重置原因并点击“确认重置”。
  5. 安全交付新密码；旧密码会立即失效。
重置的影响只处理登录凭证，不改变经销商组织或账号可用状态；重置操作和原因会写入操作日志。
09

操作五：查看设备测试记录

  1. 选择正确大区，进入“设备测试记录”。
  2. 按设备 ID、APP 测试账号、用户 ID 或添加时间范围查询。
  3. 点击设备 ID 或“查看设备详情”继续核对。
  4. 添加次数大于 1 时，点击次数或展开按钮查看历史添加记录。

主表显示最近添加账号、最近添加时间和累计添加次数。账号和时间筛选以设备最近一次添加记录为准。

10

操作六：查看操作日志

  1. 选择正确大区并进入“操作日志”。
  2. 点击“操作日期”，选择需要查询的日期。
  3. 查看操作类型、对象、来源、创建人、操作人、结果和备注。
  • 可记录创建账号、重置密码、手动清理和重试清理等后台操作。
  • 复制临时密码不会写入操作日志。
  • APP 端测试绑定和主动解绑不在此后台操作日志中记录。
11

完整场景演示

示例：华东一级经销商需要新增一个到货抽检账号。

  1. 查询“华东一级经销商”，点击结果并核对经销商 ID。
  2. 选择“中国”大区，进入“APP 测试账号”，先搜索现有账号。
  3. 点击“创建账号”，账号名称填写“华东经销商抽检账号”。
  4. 客户端选择“小鹰看看”，创建原因填写“用于到货设备抽检及异常复测”。
  5. 提交后复制临时密码，与账号名称和客户端一起安全交付指定测试人员。
  6. 测试人员登录 APP，扫码添加设备并完成配网、上线、音视频、控制或 4G 通信测试。
  7. 跟单人员在“设备测试记录”中按设备 ID 或账号查询添加情况。
  8. 测试结束后，提醒测试人员在 APP 端解绑设备。
  9. 进入“操作日志”确认账号创建记录；发生重置时，同时核对重置原因和结果。
完成标准形成“账号创建 → 密码交付 → 设备测试 → APP 解绑 → 后台追溯”的完整闭环。
12

常见问题

“创建账号”按钮是灰色，不能点击
该经销商可能已停用。停用经销商仍可查看详情，但不能创建 APP 测试账号。请核对经销商状态并联系对应管理人员。
提示“该经销商下已存在同名 APP 测试账号”
先在账号列表中查询现有账号。如确需新建，请修改账号名称，保证同一经销商下名称不重复。
创建后在列表中找不到账号
依次检查当前大区、账号查询条件和当前经销商。创建成功后，页面会自动切换到新账号所属大区和“APP 测试账号”标签。
临时密码忘记保存或交付失败
临时密码关闭后无法再次查看。请点击“重置密码”，填写原因并生成新密码，不要尝试找回旧密码。
设备测试记录查询不到
检查经销商、大区、设备 ID、账号关键词和添加时间范围。账号与时间条件只匹配设备最近一次添加记录。
测试账号无法添加某台设备
已正式激活或已有正式用户关系的设备不能再建立测试绑定。请核对设备状态，避免影响真实用户关系。
测试结束后为什么还要在 APP 端解绑
解绑用于结束临时测试关系，确保真实用户后续能够正常绑定并正式激活。后台查看记录不能代替 APP 端解绑。
13

重要注意事项

  1. APP 测试账号只用于设备抽检、样机验证和异常复测，不作为真实消费者账号使用。
  2. 测试账号禁止分享或转移设备，也不能兑换正式云存权益。
  3. 测试完成后必须在 APP 端解绑设备。
  4. 临时密码只展示一次，交付前不要关闭弹窗。
  5. 真实密码不得写入共享文档、公开群聊或工单备注。
  6. 账号创建和密码重置需填写真实、清楚的原因，便于审计。
  7. 查询账号、设备记录和日志前，先确认经销商与大区。
  8. 当前页面没有账号审批、有效期、启停或延期功能。
